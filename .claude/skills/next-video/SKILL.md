# /next-video — варианты следующего ролика

Цель: дать пользователю выбрать тему. Ничего не рендерить и не создавать эпизод до выбора.

## Шаги

1. Прочитай `docs/channel.md` (серии, список тем), `docs/metrics.md` (если есть — что зашло/не зашло),
   список `episodes/` (что уже сделано — не повторять объект и не повторять раскладку шотов).
2. Выбери 3 кандидата **из разных серий** (например: пульсар-рекорд, экзопланета, чёрная дыра/свежее открытие).
   Для «свежего» — WebSearch по новостям астрономии за последние 3–7 дней.
3. По каждому — быстрый фактчек ключевых чисел (WebSearch/WebFetch: ATNF, NASA Exoplanet Archive, arXiv, NASA/ESA).
4. Запиши `ideas/<YYYY-MM-DD>_options.md` (по-русски) — для каждого варианта:
   - **Объект** (каталожное имя) и серия; **крючок**: первая фраза EN + описание первого кадра;
   - **Почему зацепит** (вау-факт, тренд, поисковый интерес);
   - **Факты** 4–6 штук с источниками (ссылки) и пометкой уверенности;
   - **План шотов** 5–7 строк (что нового визуально относительно прошлых эпизодов);
   - **Что добавить в spacekit** (новые модули/эффекты) + оценка работы (ч) + оценка рендера (ч GPU);
   - **Риски** (спорные факты, сложная визуализация, длительность > 60 с).
5. Покажи пользователю короткую сводку трёх вариантов (по 3–4 строки) и попроси выбрать: «делаем N».

## Правила
- Только реальные объекты с измеренными параметрами; гипотезы — явно помечать.
- Не предлагать то, что потребует чужих видео/музыки как основы.
- Учитывать пропускную способность: ≤ 6 ч рендера на ролик (60 с, 1080×1920 60 fps ≈ 3–6 ч на RTX 3060).
