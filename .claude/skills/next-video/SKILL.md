# /next-video — шаг 1: worktree ролика и 3 варианта

Этот чат = один будущий ролик (`AGENTS.md`, «Конвейер чатов»). Цель шага — выбор темы пользователем.
Ничего не рендерить; папку `episodes/<ep>/` не создавать до выбора.
Канал **The Universe Inside Out** — весь космос: планеты, луны, звёзды, чёрные дыры, галактики, экзопланеты, кометы,
реальные миссии и события, масштабы, «что если». Ролики — только EN, цель 29–29,5 с, максимум 30,0 с
(`docs/shorts_format.md`). Планка — `docs/quality.md`: тема без кадра, который остановит скролл, не предлагается.

## Шаг 0 — worktree ролика

- Чат в основной копии: `python tools/video_wt.py start` → путь `…/space-shotrs.wt/epNNN`, ветка `video/epNNN`,
  номер зарезервирован. Claude — `EnterWorktree` с этим `path`; Codex — `workdir` = путь. Дальше всё — там.
- Чат уже открыт приложением в worktree (ветка не `video/…`): `python tools/video_wt.py start --here`.
- Уже на ветке `video/epNNN…` этого ролика — продолжать в ней.

## Шаги

1. Прочитай:
   - `python tools/video_wt.py status` — какие ролики сейчас в работе у других чатов (их темы не предлагать);
   - `docs/channel.md` — серии и таблица «Первые темы» (✅ = снято);
   - `episodes/INDEX.md` — что уже сделано и какими шотами (не повторять объект, раскладку шотов, тип хука);
   - `docs/quality.md` — планка картинки; `docs/spacekit.md` — матрица «есть / нет» (что потребует модулей);
   - `docs/timings.md` — с/кадр и формула ETA; `docs/metrics.md` — что зашло/не зашло;
   - `docs/competitors.md` — темы и крючки, которые зашли у конкурентов, и их слабые места;
   - `ideas/*_options.md` — строки «Выбран: …» здесь и в ветках роликов в работе
     (`git grep -h "Выбран:" <ветка> -- ideas/`).
2. Выбери 3 кандидата:
   - **вариант 1 — следующая неотмеченная тема** из таблицы `docs/channel.md` (по порядку номеров);
   - **варианты 2 и 3 — из других серий и классов объектов**, чем вариант 1, друг друга и прошлый эпизод
     («свежее» — веб-поиск по новостям астрономии и миссий за последние 3–7 дней);
   - у каждого — **money shot** (один кадр-кульминация), оценка **вау 1–5** и 2–3 визуальных референса (URL).
     Порядок вариантов в сводке — по вау, не по удобству для `spacekit`.
3. По каждому — быстрый фактчек ключевых чисел (ATNF, NASA Exoplanet Archive, JPL SSD/Horizons, arXiv, страницы
   миссий NASA/ESA); роль «фактчекер» — `docs/workflows.md`.
4. Оценки — по `docs/timings.md`: рендер = Σ кадров × с/кадр типа шота + ~30 с/шот; финал планировать на 4–6 ч
   ради качества, ≤ 6 ч (`docs/quality.md`); работа = 1–2 ч без новых модулей + 3–8 ч на каждый модуль из колонки
   «нет» `docs/spacekit.md`.
5. Запиши `ideas/<YYYY-MM-DD>_options.md` по шаблону `ideas/_TEMPLATE_options.md` (по-русски). Если файл за эту
   дату уже есть — суффикс `_2`.
6. Коммит в ветке ролика: `docs(epNNN): варианты ролика` + трейлер модели (`AGENTS.md`, «Работа агентов»).
   Дерево чистое.
7. Покажи пользователю короткую сводку трёх вариантов (по 3–4 строки: объект, крючок, money shot, вау, новое в
   spacekit, ETA рендера + полный цикл до пакета) с путём к файлу и попроси выбрать: «/make-video N» (можно с
   правками). **Стоп.**

## Правила

- Только реальные объекты/события с измеренными параметрами; гипотезы и «что если» — явно помечать.
- Не зацикливаться на нейтронных звёздах: два пульсара/магнитара подряд — только если пользователь просит.
- Не предлагать то, что потребует чужих видео/музыки как основы.
- Вариативность против «inauthentic content» (`docs/pipeline.md`, последний раздел): каждый вариант — свой тип хука
  и своя структура, не клон прошлых эпизодов.
- Пользователь отказался от всех вариантов — новые 3 в том же чате; закрыл тему — `video_wt.py finish --no-release`
  (влить ideas-файл) и `remove`: номер останется занятым.
