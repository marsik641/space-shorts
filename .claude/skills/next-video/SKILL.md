# /next-video — варианты следующего ролика

Цель: дать пользователю выбрать тему. Ничего не рендерить и не создавать эпизод до выбора.
Канал **The Universe Inside Out** — весь космос: планеты, луны, звёзды, чёрные дыры, галактики, экзопланеты, кометы, реальные
миссии и события, масштабы, «что если». Нейтронные звёзды (эп. 001) — только начало, не рамка канала.
Ролики — только EN. Новые выпуски: цель 29–29,5 с, жёсткий максимум 30,0 с;
при 60 fps цель — 1770 кадров, максимум 1799 с запасом AAC. ETA считать по этой длительности
(решение владельца 22.10.2026; docs/shorts_format.md).

## Шаги

1. Прочитай:
   - `docs/channel.md` — серии и таблица «Первые темы» (✅ = снято);
   - `episodes/INDEX.md` — что уже сделано и какими шотами (не повторять объект, раскладку шотов, тип хука);
   - `docs/spacekit.md` — матрица «есть / нет» (что потребует новых модулей);
   - `docs/timings.md` — с/кадр и формула ETA;
   - `docs/metrics.md` — что зашло/не зашло (если есть строки);
   - `docs/competitors.md` — темы и крючки, которые зашли у конкурентов (суперлативы, «монстры»), и их слабые места;
   - `ideas/*_options.md` — строки «Выбран: …» (уже взятые темы не предлагать повторно).
2. Выбери 3 кандидата:
   - **вариант 1 — следующая неотмеченная тема** из таблицы `docs/channel.md` (по порядку номеров);
   - **варианты 2 и 3 — из других серий и классов объектов**, чем вариант 1, друг друга и прошлый эпизод
     (например планета/луна Солнечной системы, экзопланета, чёрная дыра, галактика, комета, миссия; «свежее» —
     WebSearch по новостям астрономии и миссий за последние 3–7 дней).
3. По каждому — быстрый фактчек ключевых чисел (WebSearch/WebFetch: ATNF, NASA Exoplanet Archive, JPL SSD/Horizons,
   arXiv, страницы миссий NASA/ESA);
   роль «фактчекер» — `.claude/workflows.md`.
4. Оценки — **по `docs/timings.md`, не «3–6 ч»**: рендер = Σ кадров × с/кадр типа шота + ~30 с/шот; работа =
   1–2 ч без новых модулей + 3–8 ч на каждый модуль из колонки «нет» `docs/spacekit.md`. Лимит рендера ≤ 6 ч.
5. Запиши `ideas/<YYYY-MM-DD>_options.md` по шаблону `ideas/_TEMPLATE_options.md` (по-русски). Если файл за эту дату
   уже есть — суффикс `_2`.
6. Покажи пользователю короткую сводку трёх вариантов (по 3–4 строки: объект, крючок, новое в spacekit, ETA
   рендера + полный цикл до пакета к загрузке)
   с путём к файлу и попроси выбрать: «делаем N» (можно с правками).
7. Выбор записывает `/make-video` (шаг 1) в конец этого файла: `Выбран: N, дата, правки, эпизод epNNN_<slug>`.

## Правила
- Только реальные объекты/события с измеренными параметрами; гипотезы и «что если» — явно помечать.
- Не зацикливаться на нейтронных звёздах: два пульсара/магнитара подряд — только если пользователь просит.
- Не предлагать то, что потребует чужих видео/музыки как основы.
- Вариативность против «inauthentic content» (`docs/pipeline.md`, последний раздел): каждый вариант — свой тип хука
  и своя структура, не клон прошлых эпизодов.
