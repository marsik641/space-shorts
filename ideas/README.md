# Варианты следующих роликов

Сюда `/next-video` пишет `<YYYY-MM-DD>_options.md` (по шаблону `_TEMPLATE_options.md`) с тремя вариантами:
один — следующая неотмеченная тема из `docs/channel.md`, два — из других серий. Ролики только EN (канал Orbitfall). Второй файл за ту же дату — `_2`.

Выбор: «делаем N» — относится к **самому свежему** файлу (иначе назвать файл). `/make-video` дописывает в его конец
строку `Выбран: N, дата, правки, эпизод epNNN_<slug>`; по этим строкам `/next-video` не предлагает взятые темы повторно.
