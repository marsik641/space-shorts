## ETA

```
ETA_рендера = Σ_шоты (кадры × с/кадр) + ~30 с × число шотов (сборка сцены, Млечный Путь из кеша)
```

Пример ep001: 3600 кадров; v1 270×4.4 ≈ 20 мин, v2 690×3.8 ≈ 44 мин, v3–v6 2640×(6–10) ≈ 4.4–7.3 ч →
итого ≈ **6–7 ч** (а не «3–6 ч»). Лимит на ролик — ≤ 6 ч: укладываться крупными планами, сэмплами, длиной шотов
с планетами/кольцом. Прогресс идущего рендера: число PNG в `out/<ep>/9x16/frames/<шот>/` против кадров шота.
