# Пакет к загрузке (финал `/make-video`)

Отдельной команды нет: пакет собирает `/make-video` (часть B, шаги 10–13) после «ок» пользователя. Только EN.
Каркас — `episodes/_template/publish_en.md`; готовый пример — `episodes/ep001_psr_b1257/publish_en.md`.

## Что лежит в `out/<ep>/release/`

| Файл | Что | Откуда |
|---|---|---|
| `<ep>_en_1080x1920p60.mp4` | мастер, H.264 40 Мбит/с, AAC 320 кбит/с — грузить в Studio и на площадки | `build_edit.py … en` + assemble |
| `publish_en.md` | тексты и настройки загрузки | этот документ |

Только эти **два файла** (решение владельца, 18.10.2026): `_light`/`_preview`-копии не собираются и в пакет не
входят (`build_edit.py --light/--preview` остались для ручных случаев). Сборка — `python tools/release.py
episodes/<ep>/episode.json` (сначала `tools/qa.py … en` = PASS): нет мастера или `publish_en.md` — FAIL; файлы не
из текущего состава (старые копии, RU) release.py удаляет из release/ (строка DEL). Пользователю (SendUserFile) —
оба файла; если мастер не проходит по размеру — путь к `release/`.
Faststart/BT.709 Blender не пишет — сознательно без ремукса (`docs/pipeline.md`, «Оговорка про контейнер»).

## `publish_en.md`

1. **Названия** — 3 варианта, ≤ 60 символов, факт-крючок или вопрос, без кликбейт-лжи
   (пример: «This Dead Star Spins 161 Times a Second»). Отметить рекомендуемый.
2. **Описание**: 2–3 строки сути (первая строка видна в ленте) → «Visualization based on real data:» +
   ключевые параметры → **Sources** — **каждое число ролика** со ссылкой из `facts.md` (не влезает — в закреп) →
   «Rendered in Blender Cycles · scientific visualization / artist's impression» + условности (масштаб, замедление) →
   3–5 хэштегов (`#space #astronomy #<объект>`).
3. **Теги**: 5–8 (роль минимальная): объект, тип объекта, space, astronomy, science visualization, 3D render.
4. **Закреплённый комментарий**: источники коротко + вопрос зрителю (выбор следующей темы).
5. **Studio**: не для детей; категория Science & Technology; язык English; плейлист/серия (с ~30 роликов, `docs/channel.md`); **Related video**
   (long-form или прошлый эпизод по теме). «Altered or synthetic content» — **добровольно**: по справке обязательно
   для GenAI, Blender-рендер формально не GenAI; консервативно отмечать для фотореалистичных сцен, которых не было
   (метка не режет охват). TTS-озвучка может получить автометку YouTube.
6. **Слот публикации**: по сетке ниже (раздел «Расписание»); в `publish_en.md` — конкретная дата и слот.
7. **Кросс-пост (EN)**: короткие нативные подписи, без ссылок на YouTube; грузить чистый мастер (не скачивать с YouTube).
   - TikTok: из РФ загрузка новых видео заблокирована с 03.2022 (проверить); Creator Rewards — только ролики > 60 с,
     наш мастер не подходит — только охват.
   - Instagram Reels: только охват (Meta в РФ признана экстремистской, доход — юридический риск).

## Расписание (решение владельца 19.10.2026; с 20.10.2026 — ролик в день)

Обоснование и источники — `docs/growth.md`, раздел 9.

- **1 ролик в день, 14:00 ET** (US Eastern), с 20.10.2026; до этого было 3 в неделю (вт/чт/сб).
  Старт: ep001 — пн 19.10 (вышел), ep003 — вт 20.10, ep004 — ср 21.10, ep005 — чт 22.10, дальше по готовности. В Москве: **21:00** до 31.10.2026 (EDT, UTC−4),
  **22:00** с 01.11.2026 (EST, UTC−5); Лондон 19:00, Калифорния 11:00. В Studio — «Запланировать» с часовым
  поясом New York, чтобы перевод часов в США учитывался сам.
- **Один ролик в день.** Два в один день не ставить, пачкой не выкладывать: каждому — свой тест на seed-аудитории.
  Кончился запас — **пропустить день**, а не выкладывать сдвоенно и не ставить сырой ролик. Темп держится, только
  если владелец утверждает тему+сценарий примерно раз в день и рендер не простаивает (два ПК).
- **Очередь:** готовые эпизоды идут по одному в ближайший свободный день; 1–2 готовых держать в запасе, чтобы
  сетка не рвалась из-за рендера. Серии чередовать (`docs/channel.md`).
- **Готов к загрузке:** ep006 DART / Dimorphos, 42 с EN, QA PASS, мастер и `publish_en.md` в `out/ep006_dart_dimorphos/release/`. Предлагаемый слот — чт 22.10.2026, 14:00 ET (21:00 МСК); онлайн не запланирован.
- **Исключения — привязка к событию, вне сетки:**
  - **ep002 Voyager 1 — пн 16.11.2026, 14:00 ET** (запасной вариант — вс 15.11); в этот день другой ролик не ставить. Озвучка в будущем времени,
    рубеж — 18.11.2026 10:16 UTC; ≈95% просмотров Shorts набирают за первые 7 дней, поэтому раньше не выкладывать:
    окно раздачи должно накрыть новостную волну 17–20.11. Позже 18.11 10:16 UTC — только с правкой описания.
  - **FRESH FROM ORBIT** — сразу по готовности, в течение 48–72 ч от новости: здесь время решает.
- **Пересмотр слота** после 10 опубликованных роликов: Studio → Аналитика → Аудитория → «Когда ваши зрители на
  YouTube»; слот — на 1–2 ч раньше пика своей аудитории. Если ролик в день не держится — откат на 3 в неделю (вт/чт/сб),
  а не дыры по нескольку дней.
