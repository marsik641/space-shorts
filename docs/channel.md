## Позиционирование

**Реальные объекты. Реальные цифры. Кинематографичный рендер.**
Почти все космические Shorts — запись SpaceEngine, сток NASA или ИИ-картинки. Наше отличие, которое нельзя
повторить шаблоном: физически корректные рендеры **конкретных каталожных объектов** с параметрами из
публикаций прямо в кадре, «честные звуки» (пульс по реальному периоду), проверенные факты с источниками.

## Тексты

**Слоган:** EN «Real objects. Real numbers. Rendered.» / RU «Реальные объекты. Реальные цифры. Каждый кадр.»

**Описание канала (EN):**
> Neutron Frames turns real astronomical data into cinematic 60-second visualizations. Every pulsar, magnetar,
> black hole and exoplanet here is a real catalogued object — spin rates, masses, orbits and temperatures come
> from published measurements (ATNF Pulsar Catalogue, NASA Exoplanet Archive, peer-reviewed papers), with
> sources in every description. Rendered in Blender Cycles; all visuals are scientific visualizations /
> artist's impressions based on data. New Shorts every week.

**Описание канала (RU):**
> «Кадр Вселенной» превращает реальные астрономические данные в минутные кинематографичные визуализации.
> Каждый пульсар, магнитар, чёрная дыра и экзопланета здесь — настоящий объект из каталогов: период вращения,
> масса, орбита и температура взяты из опубликованных измерений, источники — в описании каждого ролика.
> Рендер — Blender Cycles; всё изображённое — научная визуализация по данным. Новые ролики каждую неделю.

## Оформление

- **Аватар:** светящийся диск нейтронной звезды + два тонких луча-конуса под углом в рамке кадрового окна;
  2 цвета (голубой луч на почти чёрном), читается на 48 px. Рендерится из `spacekit` (крупный план v1 эп. 001).
- **Баннер** 2560×1440 (безопасная зона 1546×423): кадр пульсара с сияниями из эп. 001, слоган справа,
  строка «New Shorts weekly · data-driven space visualizations».
- **В каждом ролике:** сверху мелко «Scientific visualization · real data», название объекта в первые секунды,
  вшитые субтитры, бесшовная петля конец→начало. Без интро/логотипа (первая секунда — самый сильный кадр).

## Настройки загрузки по умолчанию (YouTube Studio → Настройки → Загрузка видео)

- Категория: **Science & Technology**; язык видео и метаданных: English (RU-канал — Russian).
- Аудитория: **не для детей**. Лицензия: стандартная YouTube. Комментарии: открыты.
- Синтетический контент: «altered or synthetic» отмечать **добровольно** (консервативно) для фотореалистичных
  сцен: по справке обязательно для GenAI, Blender-рендер формально не GenAI; метка не режет охват и монетизацию.
  Учесть: TTS-озвучка может получить автометку YouTube (C2PA/детекция) в описании. Надпись
  «visualization / artist's impression» — всегда.
- Теги (влияют минимально): 5–8 — `space, astronomy, <объект>, <тип объекта>, science visualization, 3D render`.
- Описание: 2–3 строки сути + источники + 3–5 хэштегов (`#space #astronomy #pulsar`). Закреп — источники и вопрос.

## Серии (рубрики)

1. **NEUTRON FILES / «Нейтронка»** — пульсары и магнитары + «честный звук» по реальному периоду.
2. **TRUE SCALE / «Масштаб»** — сравнения по реальным радиусам и массам.
3. **ALIEN SKIES / «Небо чужих миров»** — вид с поверхности экзопланет (NASA Exoplanet Archive).
4. **EVENT HORIZON FILES / «Горизонт»** — чёрные дыры (линзирование — новый модуль spacekit).
5. **RECORD BREAKERS / «Рекорды»** — самый быстрый, тяжёлый, горячий.
6. **PHYSICS WHAT-IF / «Что если»** — только физически обоснованные сценарии.
7. **FRESH FROM ORBIT / «Свежее»** — визуализация громкого открытия за 48–72 ч.
