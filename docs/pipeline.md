# Конвейер: от выбора темы до готового к загрузке ролика

Две точки, где решает человек: **выбор темы** и **одобрение сценария+превью**. Всё остальное делает Claude Code
командами из `.claude/skills/` (их можно вызывать словами: «предложи следующее видео», «делаем вариант 2»).

```
/next-video ──► 3 варианта (pitch) ──► [ТЫ: выбираешь] ──► /make-video N
   │                                                         │
   │   факты+источники → сценарий EN/RU → шоты → превью ─────┤
   │                                                         ▼
   │                                   [ТЫ: одобряешь сценарий и контактный лист]
   │                                                         │
   │  финальный рендер (ночь) → озвучка → музыка → сведение → монтаж EN/RU → QA ─┤
   │                                                         ▼
   └──────────────────────────────── /publish-pack ──► out/<ep>/release/: mp4 EN, mp4 RU, тексты к загрузке
```

## Этап 1. `/next-video` — варианты следующего ролика

Claude смотрит `docs/channel.md` (серии, темы), `episodes/` (что уже было, чтобы не повторяться) и
`docs/metrics.md` (что зашло), и пишет `ideas/<дата>_options.md` с **3 вариантами** в разных сериях:

- объект (каталожное имя), крючок первой секунды (фраза + кадр), почему зацепит;
- 4–6 ключевых фактов с источниками (ATNF, NASA Exoplanet Archive, статьи);
- план шотов (5–7 шотов, что нового по визуалу относительно прошлых роликов);
- что нужно добавить в `spacekit` (новые модули, оценка работы) и оценка рендера (часы GPU);
- риски (спорные факты, сложная визуализация).

**Ты отвечаешь: «делаем 2»** (можно с правками: «2, но без кольца, и хук про скорость»).

## Этап 2. `/make-video <вариант>` — производство

1. **Факты.** Исследователь + фактчекер (воркфлоу) → `episodes/epNNN_<obj>/facts.md` с источниками.
2. **Сценарий.** `script_9x16.json`: 8–10 фраз EN/RU с якорями во времени (≤ 60 с, 120–150 слов EN);
   правила: факт-крючок в первой фразе, «likely/probably» для гипотез, финальная фраза подводит к петле.
3. **Сцена.** `system.py` (реальные параметры → экранный масштаб, `spacekit.orbits.video_periods`),
   новые модули в `spacekit/` при необходимости (+ регресс эп. 001 через `tools/imgdiff.py`).
4. **Шоты.** `shots_9x16.py` (5–7 шотов, 1080×1920 60 fps), `episode.json` (порядок, оверлеи, стиль субтитров).
5. **Превью.** Все шоты pct=50 → `tools/contact.py` → контактный лист + черновая озвучка `tools/tts.py`.
   Критика превью (воркфлоу из 3–5 критиков: шоты/физика/ритм) → правки.

**Ты получаешь контактный лист + сценарий и отвечаешь: «ок» или правки.** После «ок» — до конца без вопросов.

6. **Рендер.** `bash tools/render_episode.sh episodes/<ep>/shots_9x16.py v1 … vN` — в фоне, с докачкой
   (CPU не грузить параллельно). 60 с вертикали ≈ 3–6 ч.
7. **Звук.** `tools/tts.py` (EN Kokoro, RU edge-tts) → `tools/music.py` (cue-лист: гармония по шотам, удары
   пульса — по кадрам вспышек `FLASH` из лога рендера, подъёмы к склейкам) → `tools/mix.py` (−14 LUFS, пик −1 dBFS).
8. **Монтаж.** `tools/build_edit.py <episode.json> <lang>` → `editkit/assemble.py` → MP4 H.264 1080×1920p60
   40 Мбит/с + AAC 320 кбит/с 48 кГц, на каждый язык.
9. **QA.** `editkit/verify_video.py` (размер/fps/длительность ≤ 60 с, ключевые кадры: начало, каждая склейка,
   субтитры, конец=начало) + проверка, что субтитры не уходят в зоны интерфейса Shorts (низ ~20%, правый край).

## Этап 3. `/publish-pack` — пакет к загрузке

`out/<ep>/release/`:
- `<ep>_en_1080x1920p60.mp4`, `<ep>_ru_1080x1920p60.mp4`
- `publish_en.md`, `publish_ru.md`: 3 варианта названия (≤ 60 символов, факт/вопрос), описание
  (2–3 строки + источники + 3–5 хэштегов), теги, закреплённый комментарий (источники + вопрос зрителю),
  флажки Studio (не для детей; «altered or synthetic» — да/нет и почему), Related video, плейлист/серия,
  рекомендуемое время публикации, тексты для TikTok/Reels/VK Клипов/Rutube.

Загрузку делаешь ты (Studio). Автозагрузка через YouTube Data API возможна позже: OAuth-клиент в `secrets/`,
квоты 100 загрузок/сутки; у неаудированных проектов видео может блокироваться в private — сначала тест.

## Этап 4. Через 48 ч и 7 дней — метрики

Скинь скриншот Studio (Shorts: viewed vs swiped away, APV, engaged views, подписки) — Claude дописывает строку
в `docs/metrics.md` и учитывает это в следующем `/next-video`.

## Правила конвейера (против «inauthentic content»)

- Новый объект → новые шоты и драматургия; библиотека — кирпичи, не шаблон. Минимум 1 новый визуальный приём
  на ролик (новый модуль, ракурс, эффект).
- Музыка — новая гармония/темп/тембр на каждый ролик (`music_cues.json`), «честный звук» объекта где возможно.
- Голоса и раскладка субтитров могут быть фирменными, но хук и структура фраз — разные.
- Каждое число — с источником в описании.
