Цель: реалистичный (уровень визуализаций NASA Goddard / ESA, «научно-документальный» вид) ролик

## Окружение и запуск

- Blender: `D:\Blender\blender.exe` (в Git Bash: `"/d/Blender/blender.exe"`), Python 3.13 внутри, есть numpy, **нет scipy**.
- Запуск: `"/d/Blender/blender.exe" -b --factory-startup -P <script.py> -- <args>` (пути — Windows-абсолютные через `cygpath -w`).
- Корень проекта: папка `pulsar/` (рядом с этим файлом). `lib/` — модули, `tests/` — тест-скрипты,
  `renders/<компонент>/` — превью, `assets/` — сгенерированные текстуры/данные, `scenes/` — .blend.
- Общие помощники: `lib/common.py` (**только читать, не менять**): `reset_scene`, `collection/link/empty`,
  `new_material`, `math_node`, `setup_cycles` (OptiX), `setup_color` (AgX), `setup_compositor` (Bloom+Fog Glow+дисперсия),
  `camera/point_at`, `blackbody_rgb`, `render_still`. Нужен свой помощник — пиши в своём модуле.
- Импорт в скриптах: `sys.path.insert(0, <pulsar>/lib)`, затем `import common as C`, `import neutron_star as NS` и т.д.

### Грабли Blender 5.2 (проверено)
- Компоузер: `ng = bpy.data.node_groups.new(name, "CompositorNodeTree")`, `scene.compositing_node_group = ng`,
  выход — `NodeGroupOutput` + `ng.interface.new_socket("Image", in_out="OUTPUT", socket_type="NodeSocketColor")`.
  У `CompositorNodeGlare` параметры — **входные сокеты**: `inputs["Type"].default_value = "Bloom" | "Fog Glow" | "Streaks" ...`.
- Видео: `image_settings.media_type = "VIDEO"`, затем `file_format = "FFMPEG"`, `ffmpeg.format="MPEG4"`, `codec="H264"`.
- Point cloud: `pc = bpy.data.pointclouds.new(n); pc.resize(N)`; атрибут `radius` надо создать:
  `pc.attributes.get("radius") or pc.attributes.new("radius","FLOAT","POINT")`; заполнять `foreach_set`.
- Точечный свет в центре нейтронной звезды: у меша звезды **выключить `visible_shadow`**, иначе он сам себя затеняет и планеты тёмные.
- Объёмы с чистой эмиссией (без рассеяния) в Cycles дешёвые и почти без шума: 1080p кадр со звёздами + 2 объёмных луча + планета ≈ 6 с при 64 сэмплах.
- `bpy.ops` в фоне работают, но надёжнее создавать данные напрямую (`bpy.data.*.new`).

### Бюджет и тесты
- Превью: `pct=50` (960×540), 24–48 сэмплов. Финальный кадр 100% можно 1–2 раза для проверки.
- Целевое время финального кадра 1080p ≤ 10 с (≈1300 кадров всего). Тяжёлые эффекты — только если окупаются.
- GPU общий с другими агентами: не запускать больше одного Blender одновременно из своего агента.
- Анимация — только ключи (LINEAR для вращений/орбит), **никаких Python-драйверов** (в фоне не исполняются без autoexec).
  Motion blur включён (shutter 0.5) — ключи должны давать корректный блюр.

## Физика (реальная система, для правдоподобия)

- **PSR B1257+12** («Лич»): миллисекундный пульсар, Дева, ~2300 св. лет. Период 6,22 мс (161 об/с), поле ~9·10⁸ Гс,
  «переработанный» старый пульсар (раскручен аккрецией) → ось вращения ≈ перпендикулярна плоскости орбит планет.
  Радиус ~10–12 км, поверхность — гладкая (горы < мм), горячая; горячие полярные шапки (~1–3 МК) у магнитных полюсов.
  В видимом свете — голубовато-белый (чёрное тело > 10⁵ К → цвет ≈ предельный голубовато-белый).
  Радиус светового цилиндра c/Ω ≈ 300 км ≈ 25–30 R. Внутри — замкнутые дипольные линии поля (r = L·sin²θ), коротируют жёстко.
  Из полярных шапок — открытые линии → излучение лучами (конусы): ядро + полые конические компоненты («core + cones»).
- Планеты (почти круговые, почти компланарные, B и C ≈ в резонансе 3:2):
  - **A — Драугр**: 0,02 M⊕ (масса ≈ 2 Луны), a = 0,19 а.е., P = 25,3 сут. Маленькое безатмосферное тело с кратерами.
  - **B — Полтергейст**: 4,3 M⊕ (≈1,5 R⊕), a = 0,36 а.е., P = 66,5 сут. Тёмная каменистая суперземля, тонкая атмосфера, полярные сияния.
  - **C — Фобетор**: 3,9 M⊕ (≈1,45 R⊕), a = 0,46 а.е., P = 98,2 сут. Ледяная суперземля, дымка, полярные сияния.
- Планеты освещены почти исключительно пульсаром (точечный голубовато-белый источник) — нет «солнца»: жёсткий терминатор,
  глубокие тени, ночная сторона чёрная (кроме сияний). Ветер релятивистских частиц пульсара вызывает сияния.

### Сознательные «киношные» допущения (обязательные)
- Лучи пульсара сделаны видимыми (светящиеся объёмные конусы) — иначе нечего показывать. Но вид — физичный:
  яркость ∝ 1/z² вдоль луча, профиль ядро+кольцо, тонкая струйная структура, без жёстких краёв.
- Вращение замедлено: **0,6 об/с** во всех шотах (≈270× медленнее реального). Орбиты ускорены (своё значение в каждом шоте).
- Масштабы условны: размеры планет и звезды преувеличены в общих планах.
- Магнитный угол наклона α = 78° (лучи почти в плоскости орбит → раз за оборот луч «прожектором» проходит по планетам).

## Арт-дирекшн
- Реализм, сдержанность: тёмный космос, без кислотной насыщенности, без «скринсейвера». AgX, мягкий блум.
- Палитра: пульсар — голубовато-белый; лучи — бело-голубое ядро → фиолетово-синие края; линии поля — бледный циан, очень тонкие и слабые;
  сияния — 557,7 нм зелёный низко, 630 нм красный выше, фиолетовая кайма; планеты — приглушённые природные цвета.
- Ни одного резкого края объёма (видимой границы домена), ни фасеток на сферах, ни мерцания/шума между кадрами.

## Мир-координаты и иерархия пульсара
- `PSR_Root` (empty) — центр системы; локальная Z = ось вращения; плоскость XY = плоскость орбит.
- `PSR_Spin` (child Root) — вращение вокруг Z с `spin_hz` (ключи LINEAR, фаза `phase0_deg`).
- `PSR_Mag` (child Spin) — повёрнут на α вокруг локальной X → его локальная Z = магнитная ось (северный луч +Z, южный −Z).
- Планетные орбиты — пивоты-empty, дети `PSR_Root`, вращаются вокруг Z.

## Модули (контракты)

### `lib/environment.py` — звёзды, Млечный Путь, пылевое кольцо
- `build_starfield(scene, camera=None, n_stars=..., seed=7, brightness=1.0, galactic_plane_euler=(...))`
  Point cloud звёзд на сфере большого радиуса; если передана camera — Copy Location к камере (звёзды на «бесконечности»).
  Звёзды субпиксельные, реалистичное распределение блеска (много слабых, мало ярких) и цветов (по температурам, большинство
  слегка тёплые, немного голубых), концентрация к галактической плоскости. Видимость лучей: только камера.
- `build_milky_way(scene, strength=1.0, ...)` — world-шейдер: сгенерированная numpy эквиректангулярная HDR-текстура
  (`assets/milkyway.exr`, ~4096×2048): полоса с пылевыми прожилками, ярче к балджу, едва заметные цветовые оттенки. Очень тускло.
- `build_dust_ring(scene, parent, inner, outer, thickness, density, seed)` — тонкое клочковатое пылевое кольцо (объём,
  рассеяние вперёд), освещается светом пульсара и прожекторами лучей → видно бегущие по кольцу световые дуги.
  Проверить шум/мерцание на 3 соседних кадрах.

### `lib/neutron_star.py` — пульсар
- `build_pulsar(scene, *, location=(0,0,0), tilt_euler=(0,0,0), R=1.0, alpha_deg=78, spin_hz=0.6, phase0_deg=0,
  frame_start=1, frame_end=300, beam_length=40, beam_half_angle_deg=8, beam_intensity=1.0, light_energy=...,
  detail="close"|"far", field_lines=True, particles=True)` → dict объектов (`root, spin, mag, surface, beams, spots, light, ...`).
  Поверхность: эмиссия, горячие полярные шапки, слабая температурная «пятнистость» (видно вращение), лёгкое потемнение к краю.
  Лучи: объёмная эмиссия в конических доменах вдоль ±Z PSR_Mag (ядро+кольцо, 1/z², затухание у конца, струйки, бегущие наружу).
  Прожекторы (spot) вдоль лучей — освещают планеты/пыль при проходе луча. Точечный свет в центре (radius ≈ R).
  Линии поля (detail=close): замкнутые дипольные, тонкие, слабые, коротируют. Частицы вдоль лучей (опционально).
- `beam_axes_world(objs, frame)` → (север, юг) единичные векторы в мире.
- `key_pulse_flash(objs, camera, frame_start, frame_end)` — для дальних планов: ключи вспышки при совпадении луча с направлением на камеру.

### `lib/planets.py` — планеты
- `build_planet(scene, kind, *, radius=1.0, location=(0,0,0), parent=None, detail="close"|"far", seed=0,
  axial_tilt_deg=..., rot_period_s=..., frame_start=1, frame_end=300, aurora_strength=1.0)` → dict (`planet, atmosphere, aurora`).
  kind ∈ {"draugr","poltergeist","phobetor"}; процедурные материалы с деталями для крупного плана (планета на ~50% высоты кадра).
  Атмосфера: тонкий лимб/дымка, красивое рассеяние «на просвет» (серп). Сияния: овалы у магнитных полюсов, шторы, анимация.
- `add_orbit(scene, body, *, center_parent, a, period_s, phase_deg, frame_start, frame_end, incl_deg=0)` — орбита через пивот.
