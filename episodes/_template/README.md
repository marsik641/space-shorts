# Шаблон эпизода

Скопировать папку в `episodes/epNNN_<объект>/` и заполнить. Файлы:

| Файл | Что | Образец |
|---|---|---|
| `facts.md` | Факты с источниками (каждое число — ссылка) | — |
| `system.py` | Реальные параметры объекта → экранный масштаб (общие для всех шотов) | `ep001_psr_b1257/system.py` |
| `shots_9x16.py` | Шоты 1080×1920 60 fps на `spacekit.shot` | этот каркас, `ep001_psr_b1257/shots_9x16.py` |
| `script_9x16.json` | Озвучка EN/RU сегментами с якорями `at` (с), всего ≤ 60.0 с | `ep001_psr_b1257/script_9x16.json` |
| `episode.json` | Порядок шотов, формат, оверлеи, стиль субтитров, выход | `ep001_psr_b1257/episode.json` |
| `music_cues.json` | Гармония по шотам, удары/события, подъёмы к склейкам | `ep001_psr_b1257/music_cues.json` |
| `publish_en.md`, `publish_ru.md` | Пакет к загрузке | `ep001_psr_b1257/publish_en.md` |

Порядок работы — `docs/pipeline.md` и команда `/make-video`.
